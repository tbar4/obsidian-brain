# Obsidian Vault - Trevor Barnes

A rebuild after the last vault was lost. PARA for doing, Zettelkasten for thinking, bullet journal for days.

## The rule that holds it together

- A note lives in one folder only.
- Links do the cross referencing.
- If you cannot find it in 30 seconds, the folder is wrong, not the note.

## Folder map

| Folder | What lives here | Rule |
| --- | --- | --- |
| 00 Inbox | Fleeting captures, unprocessed | Empty it in weekly review |
| 01 Journal | Daily, Monthly, Future Log, Index | Date based, never PARA |
| 02 Projects | Short term work with outcome and deadline | Archive when done |
| 03 Areas | Ongoing responsibilities, no end date | Review monthly |
| 04 Resources | Reference you reuse | No working notes here |
| 05 Notes | Permanent notes, one idea per note | Flat, linked, in your own words |
| 06 Writing | Substack pipeline: Ideas, Outlines, Drafts, Published | One status at a time |
| 07 Library | Readwise sources, one file per book or article | Highlights live here, ideas live in 05 Notes |
| 08 Templates | All templates | Do not edit a template to take a note |
| 99 Archive | Finished projects, retired areas | Searchable, out of the way |

## Daily flow

1. Open today in `01 Journal/Daily`. Use the Daily Note template.
2. Capture fleeting thoughts in `00 Inbox` with the Fleeting Note template.
3. If a fleeting thought is worth keeping, promote it to a Permanent Note in `05 Notes`.
4. If a highlight is worth keeping, make a Literature Note in `07 Library`, then a Permanent Note in your own words.
5. End of day: migrate unfinished tasks with `>` in the Daily Note.

## Weekly flow

See `08 Templates/Weekly Review.md`. 20 minutes: inbox zero, promote or delete fleeting notes, migrate tasks, pick next week focus.

## Monthly flow

See `08 Templates/Monthly Log.md`. Carry over tasks, review Areas, archive finished Projects.

## Writing flow

Research in `07 Library` -> arguable thesis in `06 Writing/Ideas` -> outline in `06 Writing/Outlines` -> draft in `06 Writing/Drafts` -> published in `06 Writing/Published`.

Obsidian is the primary drafting home. Notion Blog Posts stays as a publish tracker and mirror, not a second draft. If you want Notion to stay primary, move the draft back there and keep Obsidian as outline only. Do not maintain two live drafts.

## Readwise

Auto sync is the default in this pack. One file per book or article in `07 Library`. Highlights stay verbatim there. Your own take goes in `05 Notes`, never as an edit to a highlight.

Setup is in `SETUP.md`.

## Backup - do this first

Your last vault was destroyed. This pack will not protect itself.

See `BACKUP.md`. Minimum: git repo plus Obsidian Sync or a cloud folder. Do the git init before you add real notes.
