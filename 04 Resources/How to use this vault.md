# How to use this vault

## When you are stuck, ask this

- Is it a task with a deadline? Put it in `02 Projects`.
- Is it ongoing with no end date? Put it in `03 Areas`.
- Is it reference you will reuse? Put it in `04 Resources`.
- Is it an idea in your own words? Put it in `05 Notes`.
- Is it a quote? Put it in `07 Library`, then make a note in `05 Notes`.
- Is it today? Put it in `01 Journal/Daily`.

## Naming

- Daily Notes: `YYYY-MM-DD`
- Monthly Logs: `YYYY-MM`
- Permanent Notes: short claim as title, for example `Dar al Islam vs Dar al Harb as authority claim`
- Literature Notes: `Author - Title`
- Projects: plain project name

## Links beat folders

Link a Permanent Note to its Literature Note and to the Essay it feeds. Do not copy the same text into three folders.
